# Jurnal de utilizare AI - Laboratorul 2
## Asistenta AI - Google Gemini

In realizarea acestui laborator, am folosit inteligenta artificiala Google Gemini pentru a ma ajuta in urmatoarele aspecte:

* Analizarea documentului PDF aferent Laboratorului 2 (Vite si JavaScript modern) si extragerea structurii exercitiilor.
* Asistenta pas cu pas in generarea si configurarea corecta a proiectului folosind Vite (`npm create vite@latest`), selectand optiunile potrivite (React, JavaScript, Oxlint).
* Generarea si explicarea functiilor JavaScript pentru prelucrarea imutabila a listelor, folosind metode moderne precum `map`, `filter`, `reduce` si operatorul `spread`.
* Depanarea erorilor intampinate pe parcurs: 
  - Anularea unei comenzi gresite in terminal (`Ctrl+C`).
  - Rezolvarea erorilor de import/export (`does not provide an export named` si `ReferenceError` din `main.jsx`).
  - Identificarea si corectarea unei erori de sintaxa (`Unexpected token` / cod neterminat) pe baza log-urilor din terminal.
* Clarificarea modului in care functioneaza comanda `git push origin main`, confirmand ca aceasta afecteaza strict repository-ul curent, fara a pune in pericol alte proiecte.

## Contributia si intelegerea mea:
Declar ca am inteles codul generat si explicatiile primite. Conceptele predate (module JavaScript, manipularea listelor fara a le modifica pe cele initiale, si cererile asincrone cu `fetch`) imi sunt clare.

Contributia mea personala la acest proiect a constat in:

* Configurarea si curatarea noului mediu de dezvoltare bazat pe Vite (stergerea fisierelor inutile si golirea fisierelor CSS).
* Crearea manuala a structurii de foldere necesare in interiorul directorului `src` (`data`, `utils`, `api`).
* Integrarea pas cu pas a codului in modulele specifice si testarea manuala a functionalitatilor direct in consola browserului.
* Identificarea si semnalarea problemelor si erorilor aparute in consola, urmate de aplicarea corecturilor necesare in codul sursa.
* Gestionarea independenta a serverului local (`npm run dev`) si executarea comenzilor Git pentru pregatirea si salvarea proiectului.
